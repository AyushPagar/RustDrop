# RustDrop

RustDrop is a lightweight file-sharing app built with Rust. Upload files from one device and download them on another device connected to the same Wi-Fi network.

## Features

- Upload files from your browser
- Download shared files on nearby devices
- Drag and drop files into the dashboard
- Store uploads locally on the computer running RustDrop
- Responsive dashboard for phones and computers

## Requirements

- [Rust](https://www.rust-lang.org/tools/install)
- Devices connected to the same local Wi-Fi network

## Run RustDrop

In PowerShell, open the project folder and run:

```powershell
cargo run
