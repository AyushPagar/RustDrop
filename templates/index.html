      ✳QUICK GUIDE

      Share in a few steps.

      RustDrop is designed for devices connected to the same Wi-Fi network.

      1. 1

        Connect to the same Wi-FiUse the same trusted local network on both devices.

      2. 2

        Find this computer's Wi-Fi IPOn Windows, open PowerShell and run ipconfig. Under Wi-Fi, note the IPv4 Address, for example 192.168.0.107.

      3. 3

        Open RustDrop on your phoneOn the same Wi-Fi, visit http://192.168.0.107:3000. Replace the example IP with the IPv4 Address from step 2.

      4. 4

        Upload or download filesUpload files on either device. They will appear under Shared files on both devices to download.
